你要为我开发 **Jarvis（暂用代号）个人 AI 操作系统第一代完整可用原型**。请先仔细阅读与本文件同目录的 `Jarvis_产品与技术设计总书.md` 和 `30天任务清单.md`，并严格使用 `assets/Jarvis_第四版_唯一视觉母版.png` 作为唯一角色外观参考。

## 必须遵守

- **无需再次向我问40多个产品选择题**。需求已经定稿。只对实际阻塞开发且无法安全推断的条件提出简短问题。
- **不使用Spring Boot**：后端 Python FastAPI + LangGraph + DeepSeek API；MySQL/Redis；2核2GiB阿里云ECS；Win11 RTX4060 PC Worker。客户端 Android Kotlin/Jetpack Compose，在线版 React+Three.js，部署魔搭创空间。
- 角色**不是Q版**。最终使用用户选的第四版原图、7～7.5头身、男深色短发女银灰长发、银白黑装甲、蓝色能量核心与全息飘带。中央大图与各角度必须来自同一模型，不得“近似替换”。当前没有GLB成品；先用有声明的占位素材推进接口，待我提供GLB后替换。
- 先做**真实业务闭环**：账号/游客 → 对话/任务规划 → Trust AI审批 → 日程/待办执行 → 晨报 → 候选记忆审批 → 个性化复用 → 端云知识检索。视频或动态3D不能代替真实后台行为。
- 深度联网、手机通知感知、私有文件、健康数据按最小授权设计。不能把模拟睡眠数据当成真机读取；PC离线不能擅自将私有资料传云。
- 任何新场景和外部应用操作受平台API限制，不承诺任意App自动控制。
- 使用 `.env.example`，不要在前端、日志、提交文件中存放真实密钥；不要使用我的实际用户数据制作公开演示。

## 第一轮开发请先完成以下交付，再继续下一步

1. 生成 monorepo 骨架（android/web/server/pc-worker/shared/assets/infra/docs），并可一键启动后端和Web。
2. 给出选择 Android 3D 渲染技术的对比与短PoC：Filament/SceneView 或安全WebView复用Three.js；只选一条实施路径。
3. 实现 FastAPI 健康检查、DeepSeek服务端调用、MySQL迁移、Redis连通、Android测试页和Web实时对话测试页。
4. 建立统一 `Job`、`Permission`、`MemoryCandidate`、`HudSchema` 契约和最小权限校验。
5. 写出第一周验收脚本、运行命令及下一阶段计划，不要只给我空页面和一堆模块名。
