# Jarvis 项目交付包（给 Codex）

本交付包来自产品方案讨论的已确定选择。**正式产品名待定**；“Jarvis”为暂时代号。

## 最推荐的使用方式

1. 将整个文件夹或 ZIP 放进 Codex 项目工作目录。
2. 让 Codex 首先阅读 `Codex_开工说明.md`，其次全文阅读 `Jarvis_产品与技术设计总书.md`、`30天任务清单.md`。
3. 确认 `assets/Jarvis_第四版_唯一视觉母版.png` 已在目录内；该图是**用户确认的第四版设计唯一外观母版**，不可替换。
4. 按每周关卡完成、测试后再推进；本包是设计与实施说明，**不包含已经开发完成的系统代码**。

## 包内文件

- `Jarvis_产品与技术设计总书.md`：完整PRD+技术架构+交互+数据库/API+Trust AI+端云协同+演示
- `Codex_开工说明.md`：可直接交给 Codex 的首轮执行任务
- `30天任务清单.md`：以验收条件为中心的30天分期任务
- `assets/Jarvis_第四版_唯一视觉母版.png`：用户已选的第四版角色原图

## 防止走偏的要点

**终版比例为真人比例，不是4.5–5头身Q版；Python FastAPI+LangGraph，不是Spring Boot；真实权限与记忆审批，不是模拟审批；本地PC真实运行嵌入检索，不是把电脑当公网静态文件服务器。**
